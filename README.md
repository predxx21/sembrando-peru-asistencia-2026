# Sistemas de Asistencia - Sembrando Perú

Aplicación de inicio de sesión creada con Next.js y React.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Abre `http://localhost:3000` en el navegador.

## Estructura

```text
app/                 Rutas, layout y estilos globales de Next.js
components/auth/     Componentes React del inicio de sesión
public/              Recursos estáticos públicos
```
